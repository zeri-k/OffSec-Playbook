# 시나리오명

## 시나리오 개요

`[어떤 시작 상태]에서 [어떤 공격 경로]를 거쳐 [무엇을 얻거나 확인하는지]` 한 문장으로 적는다.

특정 HTB 장비의 풀이 기록이 아니라 여러 환경에서 다시 사용할 수 있는 실전 경로로 작성한다. IP, 호스트명, 계정과 자격 증명은 플레이스홀더로 일반화한다.

## 기준 구조

명령 실행 호스트, 중간 경유 호스트, 최종 대상을 구분한다.

```text
<ATTACK_HOST>
  -> <PIVOT_HOST>
    -> <TARGET_HOST>
```
