## 판단 경로

상세 명령과 도구 옵션을 반복하지 않고 실제 공격기법으로 연결한다.
여러 라우터가 겹치면 현재 관찰값을 가장 많이 좁히는 구체적인 라우터를 우선한다.

첫 열에는 연결된 공격기법을 실행하기 전에 이미 확인한 상태·입력·권한만 적는다. 연결된 기법 안에서 수행할 진단 단계나 그 기법을 실행한 뒤 나타나는 성공·실패 출력은 첫 열에 적지 않는다.

| 현재 보유 상태·입력 | 선택할 공격기법 또는 수동 확인 | 성공하면 얻는 상태 | 다음 상태 라우터 | 선택 기준·미충족 시 확인 |
|---|---|---|---|---|
|  | `[[실제 공격기법]]` 또는 `수동 확인: 확인할 조건` |  | `[[실제 다음 상태 라우터]]` |  |

- 상태를 바꾸는 실행 절차에는 실제 `02_공격기법` 링크를 적는다.
- 서비스·현재 계정·도달성처럼 다음 기법을 고르기 위한 조건 확인뿐이고 대응 기법 문서가 없다면 `수동 확인:`으로 시작해 확인할 조건을 적는다.
- 한 판단 행은 하나의 실행 선택을 표현한다. 서로 다른 전제 조건을 가진 기법은 행을 나눈다.
- 결과가 셸·자격 증명·파일 접근·고권한·AD 계정·내부망 경로로 바뀌면 실제 `00_시작/상태별 라우터` 문서 링크를 적는다.

## 상태 재평가

- 권한, 현재 계정, 현재 가능한 행위, 보유 정보 또는 네트워크 위치가 바뀌면 현재 상태를 다시 판단한다.

## 관련 노트

- 실제 존재하며 이 흐름에서 사용하는 서비스·기법·도구만 연결한다.
