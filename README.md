# OffSec Playbook

서비스·상태 기반 Playbook입니다. 서비스 식별, 현재 접근 상태, 재사용 가능한 공격 경로를 기준으로 다음 검증 행동을 선택할 수 있도록 구성합니다.

Obsidian 기반 프로젝트입니다. `[[위키링크]]`를 따라 서비스·기법·도구·시나리오 문서를 오가며 탐색할 수 있으므로, 전체 탐색은 Obsidian에서 여는 것을 권장합니다.

## 구조

- `포트별 서비스 -> 공격기법 -> 공격도구`: 식별한 포트·서비스에서 서비스별 확인과 공격기법, 도구 사용법으로 이어집니다.
- `현재 상태 -> 상태별 라우터 -> 다음 행동`: 현재 플랫폼, 계정, 가능한 행위, 권한, 보유 정보, 네트워크 위치와 목표에서 다음 행동을 고릅니다.
- `시나리오 -> 재사용 가능한 공격 경로`: 여러 서비스·호스트·기법·도구를 단계별로 연결하고 실패 분기와 완료 기준을 제공합니다.

## 포함하지 않는 정보

실제 고객·조직 정보, 실습 결과와 증적, 자격 증명·토큰·해시·플래그는 포함하지 않습니다.

## 구성

- `00_시작`: 진입 문서와 상태별 라우터
- `01_포트별 서비스`: 서비스 식별 후의 확인과 분기
- `02_공격기법`: 조건, 실행, 관찰, 상태 전환을 갖춘 세부 작업
- `03_공격도구`: 도구 문법, 옵션, 입력과 고유 출력
- `04_시나리오`: 재사용 가능한 다단계 공격 경로
- `99_템플릿`: 실전 문서 작성 골격
