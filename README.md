# OffSec Playbook

서비스·상태·목표를 기준으로 다음 검증 행동을 선택하는 Obsidian 기반 Playbook입니다.

포트와 서비스에서 공격기법·도구로 이동하거나, 현재 확보한 접근·권한·정보에서 상태별 라우터를 선택할 수 있습니다. 여러 호스트와 기법을 연결해야 할 때는 재사용 가능한 시나리오를 따라갑니다.

문서는 `[[위키링크]]`와 Base 색인으로 연결되어 있으므로, 전체 탐색에는 이 저장소를 Obsidian Vault로 여는 것을 권장합니다.

## 시작하기

[`00_시작/Playbook.md`](00_시작/Playbook.md)를 진입점으로 사용합니다.

현재 상태를 다음 요소로 나누면 적절한 라우터와 후속 문서를 선택하기 쉽습니다.

`네트워크 위치 + 대상 플랫폼 + 현재 계정 + 현재 가능한 행위 + 현재 권한 + 보유 정보 + 목표`

인증 성공, 실제 세션 확보, 로컬 관리자·root 권한, 도메인 권한은 서로 다른 상태로 구분합니다. 새로운 계정·권한·파일·서비스·네트워크 경로를 확보했거나 목표가 바뀌면 현재 상태를 다시 평가합니다.

## 탐색 흐름

- `포트·서비스 -> 서비스 문서 -> 공격기법 -> 공격도구`: 발견한 포트, 프로토콜과 제품 단서에서 서비스별 확인 절차와 실행 기법으로 이어집니다.
- `현재 상태 + 목표 -> 상태별 라우터 -> 공격기법`: 셸·세션, 자격 증명, 파일 접근, 권한과 네트워크 위치를 기준으로 다음 행동을 선택합니다.
- `시나리오 -> 단계별 기법·도구 -> 완료 기준`: 여러 서비스와 호스트를 잇는 공격 경로를 실행 위치, 성공 출력, 상태 변화와 실패 분기로 나누어 제공합니다.
- `공격기법·공격도구 -> 공통 원리`: 여러 기법이 공유하는 구성 요소, 동작 과정, 조건과 결과 해석을 함께 확인합니다.

## 구성

- `00_시작`: 홈, 상태별 라우터, Active Directory 안내와 전체 탐색 색인
- `01_서비스`: 포트·프로토콜·제품 식별 후의 확인 절차와 공격기법 분기
- `02_공격기법`: 실행 조건, 명령, 확인할 출력, 실패 분기, 상태 변화와 복구 절차
- `03_공격도구`: 도구별 문법, 옵션, 입력 형식과 고유한 출력 해석
- `04_시나리오`: 여러 호스트·서비스·기법·도구를 연결한 재사용 가능한 다단계 경로
- `05_공통 원리`: 여러 공격기법이 공유하는 기술 구성 요소와 동작 원리

## 포함하지 않는 정보

실제 고객·조직·프로젝트·대상 정보, 작업 로그, 실습 결과와 증적, 자격 증명·토큰·해시·플래그 원문은 포함하지 않습니다.

## 이용 목적과 책임

본 문서는 적법한 권한을 부여받은 대상과 범위 내에서 수행하는 보안 점검, 교육 및 연구를 목적으로 제공합니다. 권한 없는 시스템 접근, 공격, 침해 또는 기타 위법 행위를 권장하거나 허용하지 않습니다.

본 문서는 별도의 보증 없이 현재 상태로 제공됩니다. 본 문서의 사용으로 발생하는 서비스 중단, 데이터 손실, 보안 사고, 법적 분쟁 및 기타 직간접적인 손해에 대해 작성자는 관련 법령이 허용하는 범위에서 책임을 지지 않습니다. 사용자는 자신의 행위와 그 결과에 대한 책임을 집니다.
