# fping

## 도구 개요

`fping`은 여러 IP에 ICMP Echo 요청을 보내 응답한 주소와 손실 통계를 빠르게 정리하는 호스트 확인 도구다. CIDR 전체에서 우선 조사할 주소를 좁히기 좋지만, 무응답은 ICMP 차단일 수 있어 호스트 부재를 확정하지 않는다.

## 필요한 입력과 실행 환경

- 실행 위치: 대상 CIDR에 직접 또는 피벗 경유로 접근 가능한 Linux 호스트
- 필요한 입력: 정확한 대상 CIDR
- 권한 조건: ICMP 요청 전송 가능

## 표준 사용법

`<TARGET_CIDR>`은 실행 호스트에서 도달 가능한 IPv4/IPv6 CIDR(예: `192.0.2.0/24`)이다. ICMP 응답이 없다고 호스트나 서비스가 없다고 결론 내리지 않는다.

```bash
fping -asgq <TARGET_CIDR>
```

## 대표 예시

```bash
fping -asgq <TARGET_CIDR>
```

확인할 출력:

- 응답한 IP 목록.
- `targets`, `alive`, `unreachable`, `timeouts`, `ICMP Echo Replies` 집계.

## 주요 옵션

| 옵션 | 의미 | 사용하는 상황 |
|---|---|---|
| `-a` | 응답한 대상 표시 | alive IP 목록을 만들 때 |
| `-s` | 실행 종료 후 통계 표시 | 전체 요청과 응답 수를 비교할 때 |
| `-g` | CIDR에서 대상 목록 생성 | 대역 전체를 입력할 때 |
| `-q` | 대상별 상세 오류를 줄임 | 응답 IP와 최종 통계에 집중할 때 |

## 도구 고유 출력

| 출력·상태 | 의미 | 다음 확인 |
|---|---|---|
| IP 주소 한 줄 | 해당 대상이 ICMP Echo Reply를 반환함 | 서비스 열거 대상 후보로 추가 |
| `<N> alive` | 응답 호스트 수 | 공격 호스트 자체 포함 여부 확인 |
| `<N> unreachable` | 도달 불가 응답 또는 경로 문제 | 호스트 부재로 단정하지 않고 route·방화벽 확인 |
| `<N> timeouts` | 응답 대기 만료 | 다른 프로토콜의 단서와 교차 검증 |
