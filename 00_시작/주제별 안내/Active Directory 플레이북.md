# Active Directory 플레이북

Active Directory(AD) 작업의 전체 흐름과 주제별 진입점을 찾는 안내다. 실제 조건 비교와 다음 기법 선택은 연결된 상태 라우터에서 수행한다.

시작할 때는 명령 실행 호스트의 네트워크 위치, 그 호스트에서 도달하는 대상 주소·포트·서비스, 현재 운영체제 계정과 AD 계정, 보유한 비밀번호·NT hash·AES key·ticket, 이미 검증한 로컬·도메인 권한을 따로 기록한다. 사용자 이름을 아는 것, 인증 자료를 보유한 것, 특정 서비스 인증이 성공한 것과 그 서비스에서 관리 권한을 얻은 것은 서로 다른 상태다.

## 현재 상태에서 시작

| 현재 상태·목표 | 먼저 열 문서 | 다음에 확정할 것 |
|---|---|---|
| 내부망에 있지만 사용할 AD 계정이 없음 | [[무인증 내부 네트워크에서 AD 단서 확인\|무인증 AD 단서]] | 호스트·도메인 컨트롤러(DC)·도메인·사용자 후보와 필요한 포트 도달성 |
| AD 계정이 있고 도메인 객체·그룹·권한 관계를 확인하려 함 | [[AD Identity 확인 후 도메인 컨텍스트 열거\|AD 계정·객체]] | 도메인·DC·현재 계정과 실제로 읽거나 제어할 수 있는 객체 범위 |
| 비밀번호·NT hash·AES key·ticket의 사용처를 찾으려 함 | [[확보한 자격 증명으로 원격 접근 경로 선택\|자격 증명 사용처]] | 지원 서비스의 인증 성공, 서비스 권한, 세션과 관리자 권한 |
| ACL·BloodHound에서 특정 객체 제어권을 확인함 | [[AD 객체 제어권 확보 후 악용 경로 선택\|AD 객체 제어권]] | 현재 SID·대상 객체·권한 종류·상속 범위와 대응 기법 |
| 자식 도메인 장악 또는 다른 trust 경로를 검토함 | [[자식 도메인 장악 후 부모 도메인 경로 선택\|자식-부모 도메인 경로]] | trust 방향·경계, 필요한 key·SID와 대상 서비스 도달성 |
| DC나 다른 대역에 닿지 않음 | [[내부망 경로 확보 후 피벗 구성\|피벗 경로]] | 중간 호스트의 실행 가능성, 경로 유형과 실제 DC 포트 도달성 |
| Windows·Linux 호스트의 로컬 권한이 목표임 | [[Windows 셸 또는 세션 확보 후 컨텍스트 열거\|Windows 셸]] 또는 [[Linux 셸 확보 후 초기 열거와 권한 상승\|Linux 셸]] | Windows는 현재 프로세스 액세스 토큰, Linux는 EUID와 로컬 상승 후보. AD 계정 보유 여부와 별도로 판단 |

## 주제별 탐색

아래 표는 세부 조건을 판정하지 않는다. 현재 상태와 목표에 맞는 라우터를 연 뒤 그 문서의 판단 표에서 실제 기법을 선택한다.

| 찾는 주제 | 상세 선택 위치 |
|---|---|
| DC·도메인·사용자 후보, 인증 전 열거 | [[무인증 내부 네트워크에서 AD 단서 확인\|무인증 AD 단서 라우터]] |
| 사용자·컴퓨터·그룹·SPN·DNS·SMB·GPO·trust·보안 구성 | [[AD Identity 확인 후 도메인 컨텍스트 열거\|AD 계정·객체 라우터]] |
| 비밀번호·hash·key·ticket과 원격 서비스 인증 | [[확보한 자격 증명으로 원격 접근 경로 선택\|자격 증명 라우터]] |
| 객체 ACL, 그룹·사용자·SPN·`msDS-KeyCredentialLink` 제어 | [[AD 객체 제어권 확보 후 악용 경로 선택\|객체 제어권 라우터]] |
| 자식 도메인 장악 뒤 부모 도메인, 포리스트·도메인 trust | [[자식 도메인 장악 후 부모 도메인 경로 선택\|자식-부모 도메인 라우터]], [[AD 도메인 트러스트 열거와 공격 경로 식별\|trust 열거]] |
| 로컬 관리자·SYSTEM·root에서 필요한 후속 작업 | [[고권한 세션 확보 후 후속 판단\|고권한 라우터]] |

## 상태를 확대 해석하지 않기

- 사용자 이름 후보, 인증 자료 보유, 서비스 인증 성공, 실제 세션, 로컬 관리자, Domain Admin 멤버십과 DCSync 가능성은 각각 다른 상태다.
- ticket 생성이나 서비스 접근 성공만으로 SYSTEM 셸 또는 AD 고권한을 선언하지 않는다.
- 로컬 권한 상승은 현재 플랫폼의 셸 라우터에서, 도메인 객체 권한은 AD 라우터에서 현재 목표로 선택한다.
- 실패하거나 새 계정·권한·세션·네트워크 위치를 얻으면 [[Playbook|홈]]에서 상태와 목표를 함께 다시 고른다.
