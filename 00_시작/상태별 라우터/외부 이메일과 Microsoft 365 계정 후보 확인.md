# 외부 이메일과 Microsoft 365 계정 후보 확인

## 상태 라우터 개요

대상 도메인과 이메일·User Principal Name(UPN) 후보는 있지만 유효 계정과 비밀번호는 확인하지 못한 상태에서 사용한다. 서비스별 응답으로 사용자 후보를 먼저 좁히고, 잠금 정책과 단일 비밀번호 후보를 확보한 뒤에만 인증 검증으로 넘어간다.

|---|---|---|---|---|

## 상태 재평가

- 사용자 후보 확인은 비밀번호 일치나 계정 활성 상태를 뜻하지 않는다.
- 공개 페이지·문서 metadata·유출 레코드에서 문자열을 찾은 상태는 사용자 후보 수집이며 현재 AD·메일·Microsoft 365 계정 존재를 뜻하지 않는다.
- 비밀번호 일치 후보가 생기면 계정·서비스·MFA 조건을 분리해 [[확보한 자격 증명으로 원격 접근 경로 선택]]에서 다시 판단한다.
- 메일함 읽기 권한까지 확인한 경우에만 [[IMAP POP3 메일함 수집]]으로 이동한다.
