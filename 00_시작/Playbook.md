# OffSec Playbook

이 Vault는 서비스와 현재 상황에서 다음 공격기법과 도구를 빠르게 선택하는 실행 Playbook이다. 각 실전 문서는 필요한 조건, 실행 명령, 확인할 출력과 다음 행동을 독립적으로 제공한다.

## 가장 먼저 확인할 것

공격 이름부터 고르지 말고 현재 상태를 다음 순서로 적는다.

1. 명령을 실행할 위치: 외부 공격 호스트, 내부 호스트, 피벗 뒤 호스트 중 어디인가.
2. 지금 접근 가능한 대상: 어떤 IP·호스트의 어느 포트·서비스까지 연결되는가.
3. 현재 계정과 권한: 무인증, 일반 사용자, 로컬 관리자, root, SYSTEM, 도메인 사용자 중 무엇인가.
4. 보유 정보: 사용자명, 비밀번호, NTLM hash, Kerberos ticket, key, 읽거나 쓸 수 있는 파일 중 무엇이 있는가.
5. 현재 가능한 행동: 서비스 연결, 로그인 시도, 파일 읽기·쓰기, 명령 실행, GUI 조작 중 어디까지 가능한가.
6. 목표: 정보 수집, 인증 성공, 파일 접근, 셸, 권한 상승, 자격 증명 또는 다른 네트워크 접근 중 무엇을 얻으려는가.

각 서비스·상태별 라우터에서는 위 조건으로 지금 실행할 수 있는 공격을 선택하고, 성공하면 새로 얻는 정보·접근·권한을 다음 상태로 다시 평가한다.

## 무엇을 보고 있는가

포트나 서비스가 출발점이면 `01_포트별 서비스 -> 02_공격기법 -> 03_공격도구` 순서로 확인한다.

- 웹: [[80_443_HTTP_HTTPS]], [[8080_8443_Web_Alt]]
- 파일 서비스: [[21_FTP]], [[445_SMB]], [[111_2049_NFS]], [[873_Rsync]], [[69_TFTP]]
- 원격 접근: [[22_SSH]], [[3389_RDP]], [[5985_5986_WinRM]], [[135_WMI]]
- 인증·디렉터리: [[88_Kerberos]], [[389_636_LDAP]]
- 데이터베이스: [[1433_MSSQL]], [[3306_MySQL]], [[1521_Oracle_TNS]]
- 인프라: [[53_DNS]], [[161_162_SNMP]], [[623_IPMI]]

- Active Directory 전체 흐름: [[Active Directory 플레이북]]

- 웹 서비스와 입력 지점: [[웹 서비스 발견 후 Foothold 확보]]
- READ/WRITE 가능한 파일 서비스: [[파일 서비스 접근 후 자격 증명과 초기 접근 연결]]
- 비밀번호, hash, key 또는 ticket: [[확보한 자격 증명으로 원격 접근 경로 선택]]
- Linux 셸과 로컬·AD/Kerberos 계정: [[Linux 셸 확보 후 초기 열거와 권한 상승]], [[AD Identity 확인 후 도메인 컨텍스트 열거]]
- Windows 셸과 로컬·도메인 계정: [[Windows 셸 또는 세션 확보 후 컨텍스트 열거]], [[AD Identity 확인 후 도메인 컨텍스트 열거]]

## 실전 공격 경로

여러 호스트·서비스·기법을 순서대로 연결해야 하는 작업은 `04_시나리오`에서 전체 경로를 확인한다. 상태별 라우터와 달리 시나리오는 각 단계의 실행 위치, 실제 명령, 성공 출력, 실패 분기와 완료 기준을 함께 제공한다.

- [[3홉 피벗팅으로 DC 열거]]

## 어디에 있는가

현재 상태는 다음 축을 따로 확인한다.

| 상태 축 | 예시 |
|---|---|
| 대상 플랫폼 | Linux, Windows, Unix, 네트워크 장비 |
| 현재 계정 | 없음, 로컬 사용자, 도메인 사용자, 서비스 계정, root, SYSTEM |
| 현재 가능한 행위 | 서비스 연결·인증, 파일 읽기·쓰기, 셸 명령 실행, GUI 조작 |
| 현재 권한 | 익명, 사용자, 로컬 관리자, root, 도메인 권한 |
| 보유 정보 | 사용자명, 비밀번호, hash, key, ticket, 파일 |
| 네트워크 위치 | 외부, 내부, 피벗 뒤 대역 |

Linux와 AD처럼 동시에 성립하는 값은 하나의 분류로 합치지 않는다.

## 무엇을 얻으려는가

목표를 기준으로 `공격기법`과 `결과별 기법` Base를 필터링한다.

- 추가 정보 또는 사용자 목록
- 서비스 인증
- 파일 읽기 또는 쓰기
- 명령 실행 또는 안정된 세션
- 자격 증명
- 로컬 관리자 또는 root
- 다른 호스트·내부망 접근

## 문서 책임

| 위치 | 답해야 하는 질문 |
|---|---|
| `01_포트별 서비스` | 이 서비스에서 어떤 단서를 확인하고 어느 기법으로 갈 것인가 |
| `02_공격기법` | ATT&CK 전술별로 어떤 조건에서 무엇을 실행하며 결과가 상태를 어떻게 바꾸는가 |
| `03_공격도구` | 주제별 도구의 정확한 문법·옵션·출력·환경 차이는 무엇인가 |
| `00_시작/상태별 라우터` | 현재 상태와 목표에서 어떤 기법을 선택할 것인가 |
| `04_시나리오` | 여러 단계의 공격기법과 도구를 어떤 순서로 실행해 목표까지 갈 것인가 |

## 문서 현황

전체 탐색 화면은 `Playbook.base`에서 확인한다. 공격기법과 공격도구 Base는 폴더별로 묶어 표시한다. 파일 탐색기에서는 주 폴더로 찾고, Tags view에서는 `환경/*`, `서비스/*`, `기능/*` 태그를 눌러 여러 폴더를 가로질러 찾는다.
