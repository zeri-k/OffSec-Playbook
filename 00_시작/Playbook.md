# OffSec Playbook

이 홈은 지금 확인한 상태와 현재 목표를 함께 보고 다음 문서를 고르는 진입점이다. 상태가 여러 개면 하나를 버리지 말고, 지금 하려는 작업에 직접 답하는 라우터를 선택한다.

## 지금 어디에서 시작하는가

| 지금 확인한 상태 | 첫 선택 | 다음에 확인할 것 |
|---|---|---|
| 포트·서비스를 발견함 | 아래 서비스 묶음 또는 [서비스 전체 보기](Playbook.base#서비스) | 서비스 고유 단서 → 공격기법 → 필요한 도구 |
| 셸·세션·명령 실행을 확보함 | [[Linux 셸 확보 후 초기 열거와 권한 상승\|Linux 셸]], [[Windows 셸 또는 세션 확보 후 컨텍스트 열거\|Windows 셸]], [[Meterpreter 세션 후속 행동\|Meterpreter]], [[MSSQL 인증 세션 확보 후 권한과 실행 경로 선택\|MSSQL 세션]] | 실제 계정·권한·가능한 행위·네트워크 위치 |

### 자주 찾는 서비스

포트나 서비스가 출발점이면 `01_서비스 -> 02_공격기법 -> 03_공격도구` 순서로 확인한다.

- 웹: [[HTTP와 HTTPS 서비스|HTTP·HTTPS]]
- 파일 서비스: [[FTP 서비스]], [[SMB 서비스]], [[NFS 서비스]], [[Rsync 서비스]], [[TFTP 서비스]]
- 원격 접근: [[SSH 서비스]], [[RDP 서비스]], [[WinRM 서비스]], [[WMI 서비스]]
- 인증·디렉터리: [[Kerberos 서비스]], [[LDAP 서비스]]
- 데이터베이스: [[MSSQL 서비스]], [[MySQL 서비스]], [[Oracle TNS 서비스]]
- 인프라: [[DNS 서비스]], [[SNMP 서비스]], [[IPMI 서비스]]

## 상태와 목표로 라우터 고르기

AD 계정, Windows 셸, 로컬 고권한과 내부망 경로는 동시에 성립할 수 있다. 현재 목표가 바뀌면 같은 상태에서도 다른 라우터를 고른다.

| 현재 목표 | 선택할 라우터 |
|---|---|
| 현재 호스트의 실행 환경·로컬 권한 확인 | [[Windows 셸 또는 세션 확보 후 컨텍스트 열거\|Windows 셸]] 또는 [[Linux 셸 확보 후 초기 열거와 권한 상승\|Linux 셸]] |
| 도메인 객체·그룹·ACL·GPO·복제 권한 관계 확인 | [[AD Identity 확인 후 도메인 컨텍스트 열거\|AD 계정·객체]] |
| 인증 자료가 어느 서비스에서 어떤 기능으로 통하는지 확인 | [[확보한 자격 증명으로 원격 접근 경로 선택\|자격 증명 사용처]] |
| 다른 대역의 도달성 확보 | [[내부망 경로 확보 후 피벗 구성\|피벗 경로]] |
| SQL·Meterpreter 고유 기능 사용 | [[MSSQL 인증 세션 확보 후 권한과 실행 경로 선택\|MSSQL 세션]] 또는 [[Meterpreter 세션 후속 행동\|Meterpreter]] |

AD 전체 흐름은 [[Active Directory 플레이북|AD 안내]], 모든 상태 라우터는 [상태 라우터 전체 보기](Playbook.base#상태%20라우터)에서 찾는다.

같은 목표·상태에서 발생한 명령·기법 실패는 현재 기법 문서의 실패 분기와 현재 라우터에서 처리한다. 목표가 바뀌거나 새 계정·권한·파일·서비스·네트워크 경로를 얻어 다음 라우터가 불명확해지면 이 홈으로 돌아와 `네트워크 위치 + 대상 플랫폼 + 현재 계정 + 현재 가능한 행위 + 현재 권한 + 보유 정보 + 목표`를 다시 맞춘다. 인증 성공을 세션이나 관리자 권한으로, 파일 읽기를 셸이나 root로 확대해서 해석하지 않는다.
