# 원격 Windows 로그온 사용자와 로컬 관리자 단서 열거

## 한 줄 판단

유효한 AD 계정과 Windows 호스트 목록이 있으면 Linux 공격 호스트에서 각 대상의 SMB에 인증해 로그온 사용자와 관리자 표시를 수집하고, 세션 현재성과 실제 원격 명령 권한을 별도로 확인하여 다음 호스트를 고른다.

## 전제 조건

| 확인할 것 | 필요한 상태 | 확인 방법 | 미충족 시 다음 확인 |
|---|---|---|---|
| 대상 호스트 | 현재성이 확인된 Windows hostname 또는 IP | DNS·SMB 서비스 응답 | [[AD 컴퓨터 객체 열거]] 결과를 DNS·서비스로 재확인 |
| 현재 계정 | 계정명이 확인된 비밀번호 | SMB 인증 결과 | 도메인·사용자 형식과 잠금 상태 확인 |
| 네트워크 경로 | 실행 호스트에서 대상 445/TCP 접근 | timeout과 SMB banner 구분 | route·방화벽·피벗 확인 |
| 조회 권한 | 로그온 사용자 정보를 반환할 권한 | 인증 성공 뒤 `Enumerated loggedon users` 확인 | 인증 성공과 조회 거부를 구분 |

## 실행

### Linux 공격 호스트에서 실행

```bash
crackmapexec smb <TARGET> -u <USER> -p '<PASSWORD>' --loggedon-users
```

`<TARGET>`은 445/TCP 응답과 DNS를 다시 확인한 Windows 호스트, `<USER>`와 `<PASSWORD>`는 SMB 인증을 요청하는 AD 계정의 입력이다. 출력의 logged-on user와 `(Pwn3d!)`는 관찰값이며 현재 세션이나 실제 token을 뜻하지 않는다.

확인할 출력:

- `[+] <DOMAIN>\<USER>:<PASSWORD>`로 SMB 인증에 성공했는지.
- `Enumerated loggedon users` 뒤의 사용자와 `logon_server`.
- `(Pwn3d!)`가 표시되는지. 이 표시는 로컬 관리자·원격 실행 후보이며 실제 명령 실행과 토큰은 후속 절차에서 확인한다.

여러 호스트를 확인할 때는 범위를 먼저 정한 대상 목록만 사용하고 호스트별 timeout·access denied·빈 결과를 구분한다.

### Windows 대상 호스트의 현재 셸에서 실행

```cmd
query user
qwinsta
```

확인할 출력:

- 사용자명, session name·ID, `Active`·`Disc` 상태와 idle time.
- 출력은 현재 또는 연결이 끊긴 세션 단서다. 다른 사용자의 자격 증명이 메모리에 남아 있는지 또는 현재 계정이 해당 세션을 제어할 수 있는지는 별도로 확인한다.

## 관찰과 상태 전환

| 관찰 | 판단 | 결과 상태 | 다음 행동 |
|---|---|---|---|
| 고권한 도메인 사용자가 로그온한 것으로 반환됨 | 해당 호스트의 현재 또는 최근 세션 후보 | 자격 증명 수집 우선 호스트 | 실제 세션 현재성과 현재 계정 권한을 확인한 뒤 [[LSASS 메모리 덤프]] 조건 검토 |
| `(Pwn3d!)` 표시 | 현재 계정의 대상 로컬 관리자·원격 실행 가능성 | 로컬 관리자 후보 | [[WMI 원격 명령 실행]] 등으로 `whoami /all`과 실제 명령 실행 확인 |
| 인증 성공, 로그온 사용자 결과 없음 | 세션 부재 또는 조회 범위 제한 | 세션 미확정 | BloodHound 수집 시점·다른 세션 조회 경로와 교차 확인 |
| access denied | SMB 인증 또는 로그온 사용자 조회 권한 부족 | 대상 권한 미확인 | 첫 실패 단계와 현재 계정 형식 확인 |
| timeout | 세션·권한 판정 전 네트워크 실패 | 대상 미확인 | DNS, 445/TCP, route·방화벽 확인 |

## 확인할 출력과 권한

- 로그온 사용자 출력은 세션 단서이며 메모리에 해당 사용자의 재사용 가능한 인증 자료가 있다는 증거가 아니다.
- SMB 인증 성공, `(Pwn3d!)`, 실제 원격 명령 실행과 상승된 관리자 토큰을 각각 다른 상태로 기록한다.
- 로컬 관리자 후보를 Domain Admin이나 DCSync 권한으로 확대 해석하지 않는다.
