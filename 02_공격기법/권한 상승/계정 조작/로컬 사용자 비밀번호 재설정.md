# 로컬 사용자 비밀번호 재설정

## 한 줄 판단

대상 Windows 호스트에서 로컬 관리자 또는 SYSTEM 명령을 실행할 수 있다면, 지정한 로컬 사용자의 비밀번호를 임시 값으로 재설정하고 그 호스트의 로컬 계정 인증 범위만 확인한다.

## 사용할 때

- SYSTEM 명령 실행은 가능하지만 대화형 로그인이나 SMB 파일 접근에 사용할 로컬 자격 증명이 필요할 때.
- AD 사용자 변경이 아니라 현재 Windows 호스트의 SAM에 있는 로컬 사용자만 변경할 때.
- 비밀번호 변경으로 기존 서비스·예약 작업·자동 로그온이 중단될 수 있음을 확인한 뒤 사용할 때.

## 전제 조건

| 확인할 것 | 필요한 상태 | 확인 방법 | 미충족 시 다음 확인 |
|---|---|---|---|
| 실행 호스트와 권한 | 목표 호스트의 상승된 관리자 또는 SYSTEM | `hostname & whoami /all` | 일반 사용자 token이면 다른 권한 상승 기법 선택 |
| 대상 계정 범위 | 로컬 SAM 사용자 | `net user <LOCAL_USER>` | 도메인 사용자이면 [[AD 사용자 비밀번호 강제 재설정]]으로 분리 |
| 정책·계정 상태 | 임시 비밀번호가 정책을 충족하고 계정이 사용 가능 | `net accounts`, `net user` | 잠금·비활성·로그온 제한 확인 |
| 복구 | 원래 값을 알고 있거나 관리자가 재설정할 계획 | 변경 전 영향 기록 | 원래 값을 모르면 자동 원복 불가 |

## 실행

### 대상 Windows 호스트에서 계정 확인과 재설정

```cmd
hostname
whoami /all
net user <LOCAL_USER>
net user <LOCAL_USER> <TEMP_PASSWORD>
```

### Linux 공격 호스트에서 로컬 계정 인증 확인

```bash
netexec smb <TARGET> --local-auth -u <LOCAL_USER> -p '<TEMP_PASSWORD>'
smbclient //<TARGET>/C$ -W WORKGROUP -U '<LOCAL_USER>%<TEMP_PASSWORD>' -c 'ls'
```

확인할 출력:

- `The command completed successfully.`는 비밀번호 변경 명령 완료를 뜻한다.
- `netexec` 인증 성공과 `smbclient`의 실제 공유 접근은 별도 결과다.
- `C$` 접근 실패만으로 비밀번호가 틀렸다고 판단하지 말고 인증 성공·관리 공유 권한·UAC 원격 제한을 분리한다.

## 관찰과 상태 전환

| 관찰 | 판단 | 결과 상태 | 다음 행동 |
|---|---|---|---|
| 변경 완료와 로컬 인증 성공 | 대상 호스트의 로컬 자격 증명 확보 | 로컬 사용자명·임시 비밀번호 | 원복 후 [[확보한 자격 증명으로 원격 접근 경로 선택]] |
| 변경 완료이나 SMB 공유 접근 거부 | 자격 증명은 유효할 수 있으나 공유 권한 부족 | 로컬 인증 후보 | SMB 인증 결과와 UAC·관리 공유 권한을 따로 확인 |
| 계정 없음 | 로컬·도메인 계정 범위 또는 사용자명 오류 | 변경 없음 | `net user`, `whoami /user`와 도메인 표기 확인 |
| 비밀번호 정책 오류 | 임시 값이 로컬 정책을 충족하지 않음 | 변경 없음 | `net accounts` 결과에 맞는 임시 값 선택 |

## 확인할 출력과 권한

- 로컬 비밀번호 변경은 해당 호스트의 SAM 계정에만 적용된다.
- 로컬 관리자 그룹 멤버십과 원격 UAC 제한 때문에 인증 성공, 관리 공유 접근과 원격 명령 실행 결과가 달라질 수 있다.

## 변경 영향과 복구

| 변경 대상 | 예상 영향 | 검증 방법 | 복구 절차 |
|---|---|---|---|
| 로컬 사용자의 비밀번호 | 기존 로그온·서비스·작업·자동 로그온 실패 가능 | 계정 사용처와 관련 서비스 상태 확인 | 원래 값을 아는 경우 `net user <LOCAL_USER> <ORIGINAL_PASSWORD>` |
| 원래 비밀번호를 모르는 계정 | 자동 원복 불가 | 변경 전에 복구 담당과 방법 확인 | 관리자가 새 비밀번호를 재설정하고 종속 서비스 갱신 |
