# 네트워크 트래픽 자격증명 수집

## 한 줄 판단

pcap을 읽을 수 있는 분석 호스트나 대상 인증 트래픽을 관찰할 수 있는 캡처 호스트가 있으면 평문 사용자명·비밀번호, NetNTLM challenge-response, Kerberos principal·ticket·AS-REP/TGS 암호문을 형식별로 추출해 오프라인 비밀번호 복구·relay·서비스 인증 검증으로 분기한다.

## 사용할 때

- 현재 보유 정보: 실습 pcap 파일 또는 대상 인증 트래픽을 볼 수 있는 인터페이스와 분석할 호스트·시간·프로토콜 단서를 확보했다.
- 명령 실행 위치와 도달성: 오프라인 분석은 pcap이 저장된 분석 호스트에서, 라이브 캡처는 대상 트래픽이 실제로 지나가는 캡처 호스트의 인터페이스에서 수행한다.
- 현재 가능한 행동과 결과: FTP·HTTP·SMTP·POP3·IMAP·SNMP의 평문 인증, Windows NetNTLM challenge-response와 Kerberos ticket·AS-REP/TGS hash를 찾아 값의 종류에 맞게 서비스 검증·크래킹·relay 가능성을 판단한다.

## 실행

1. 분석 호스트와 pcap 경로 또는 라이브 캡처 인터페이스, 대상 호스트·시간 범위를 확인한다.
2. PCredz와 프로토콜 필터로 인증 교환을 좁힌다.
3. 평문 비밀번호, NetNTLM challenge-response, Kerberos ticket·AS-REP/TGS hash와 단순 사용자명·호스트 단서를 구분한다.
4. 출력이 없으면 암호화·캡처 지점·시간 범위를 확인하고, 추출 후에는 값의 형식에 맞는 후속 기법만 선택한다.

### PCredz 분석

```bash
Pcredz -f capture.pcap
Pcredz -d ./pcaps/
```

확인할 출력:

- 평문 사용자명·비밀번호, NetNTLMv1/v2 challenge-response, Kerberos ticket·AS-REP/TGS hash, HTTP Basic 인증 등과 해당 송수신 호스트·서비스.
- 파일을 열지 못하면 pcap 경로·형식·읽기 권한을, 결과가 없으면 캡처 범위와 암호화 여부를 확인한다.

### Wireshark 필터 후보

```text
http.authorization
ftp.request.command == "PASS"
smb2 || ntlmssp
```

확인할 출력:

- 인증 헤더, FTP PASS, NTLM challenge/response.

| Kerberos principal·AS-REP/TGS 암호문·ticket | Kerberos 인증 교환 또는 ticket 단서 노출 | 계정 principal, 오프라인 복구 가능한 암호문 또는 재사용 가능한 ticket 후보 | ticket 종류·principal·service·유효 시간과 암호문 형식을 확인한 뒤 해당 사용·크래킹 절차 선택 |
| 내부 호스트명, 도메인, 사용자명 | 인증 관계와 대상 정보 확인 | 내부 정보와 계정 후보 확보 | 관련 서비스에서 최소 영향 검증 |
| credential이 보이지 않음 | 트래픽 암호화 또는 캡처 범위 불일치 가능 | 자격증명 미확인 | SNI, DNS, metadata와 다른 pcap 확인 |
| hash crack 실패 | 강한 비밀번호 또는 형식/후보 문제 | hash만 확보 | relay 가능성과 서비스별 권한 검토 |
| 노이즈가 많음 | pcap 범위 과다 | 유효 패킷 미선별 | 프로토콜, 호스트, 시간으로 필터링 |

## 확인할 출력과 권한

- 평문 사용자명·비밀번호, NetNTLM challenge-response, Kerberos ticket·AS-REP/TGS hash를 서로 다른 형식으로 구분한다.
- pcap 읽기 권한과 라이브 패킷 캡처 권한은 다르며 라이브 캡처에는 별도 시스템 권한이 필요할 수 있다.
- 수집한 값의 유효성 및 서비스 권한은 실제 인증 단계에서 별도로 확인한다.
- NetNTLM challenge-response는 Windows 계정의 NT hash가 아니며, Kerberos 패킷이 보인다는 사실만으로 재사용 가능한 ticket을 확보한 것도 아니다.
