# 표적 Kerberoasting

## 한 줄 판단

공격 대상 사용자 객체에 임시 SPN이 설정됐고 현재 Windows Kerberos 세션에서 KDC에 접근할 수 있으면 해당 사용자만 지정해 TGS hash를 수집하고 SPN 원복 뒤 오프라인 크래킹한다.

## 전제 조건

| 확인할 것 | 필요한 상태 | 확인 방법 | 미충족 시 다음 확인 |
|---|---|---|---|
| 명령 실행 위치와 네트워크 경로 | Rubeus 실행 호스트에서 KDC 접근 가능 | realm·DNS·시간과 88/TCP·UDP 확인 | Kerberos 경로를 바로잡은 뒤 요청 |
| 현재 계정 또는 인증 수단 | TGS를 요청할 현재 Windows Kerberos 세션 확보 | `whoami`, `klist`와 현재 도메인 확인 | 요청자 실행 컨텍스트와 ticket 유효성 확인 |
| 공격 대상의 조건 | 대상 사용자에 고유한 임시 SPN이 표시됨 | `Get-DomainUser` 출력 확인 | [[임시 SPN 설정]]에서 변경 성공과 기준값 확인 |
| 필요한 파일·목록·주소 | TGS hash 저장 위치와 오프라인 크래킹 환경 준비 | 출력 보존 경로와 hash 형식 확인 | `$krb5tgs$` 전체 문자열을 저장할 위치 준비 |

## 실행

`<TARGET_USER>`는 [[임시 SPN 설정]]에서 SPN을 추가한 대상 사용자의 sAMAccountName이다. 이 명령의 hash 출력은 대상 비밀번호가 아니라 오프라인 크래킹 입력이며, 임시 SPN은 결과와 무관하게 정확한 값만 원복한다.

```cmd
Rubeus.exe kerberoast /user:<TARGET_USER> /nowrap
```

확인할 출력:

- `Total kerberoastable users : 1`과 정확한 공격 대상 사용자.
- `$krb5tgs$`로 시작하는 hash.
- hash가 없으면 대상 사용자의 SPN, Rubeus 대상 지정, realm·DNS·시간과 KDC 접근을 확인하고 [[임시 SPN 설정]]에서 추가한 값을 먼저 원복한다.

## 관찰과 상태 전환

| 관찰 | 판단 | 결과 상태 | 다음 행동 |
|---|---|---|---|
| 대상 사용자와 `$krb5tgs$` hash 확인 | 표적 TGS 요청 성공 | 오프라인 크래킹 가능한 TGS hash 확보 | SPN 원복 후 [[오프라인 해시 크래킹]] |
| 평문 복구 후 정상 클라이언트로 인증 성공 | 공격 대상 계정 비밀번호가 해당 서비스에서 현재 유효함 | 공격 대상 사용자의 도메인 credential 확보 | [[확보한 자격 증명으로 원격 접근 경로 선택]] |
| SPN은 표시되지만 hash 없음 | KDC 경로 또는 대상 지정 문제 | SPN 변경 상태만 남음 | 즉시 원복 후 realm·DNS·시간·KDC 확인 |
| 크래킹 실패 | 강한 비밀번호 또는 후보 부족 | TGS hash만 확보 | 원복 상태를 확인하고 크래킹 전략 재평가 |

## 확인할 출력과 권한

- 임시 SPN 설정, TGS hash 획득, 평문 복구와 실제 인증을 서로 다른 성공 단계로 판정한다.
- TGS hash는 오프라인 크래킹 입력이며 재사용 가능한 Kerberos ticket이 아니다.
- 대상 객체 상태 변경과 복구는 [[임시 SPN 설정]]에서 수행한다.
